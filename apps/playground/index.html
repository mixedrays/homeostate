homeostate

Homeostate Playground

Small apps that keep their state in an ordinary store and sync it through homeostate into a Yjs room. Every framework's playground joins the same rooms, so a change made in one shows up in all the others. Pick a framework to see its demos.

Playgrounds

    Start the playgrounds

    From the repo root, pnpm playground starts this page, every framework's playground and the WebSocket sync server they share. pnpm playground:<framework> starts a single playground with the sync server.
