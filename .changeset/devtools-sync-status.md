Show the sync at a glance. The panel's status bar shows whether the engine is connected, the
network link's state and how many keys diverged, and each opens the tab that explains it; the
notes about a disconnected engine or a link that is down moved from above the tabs into the
Network tab. While the panel is closed, a dot on the floating button flags the same problems,
and its tooltip names them. The Sync tab shows, under a diverged key, each path that differs
with its value in the store and in the backend.
